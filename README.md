## How to Use

### Option 1: Run on Kaggle
Open any notebook from my Kaggle Code page and click “Copy and Edit”:
- https://www.kaggle.com/ibrahimqasimi/code

### Option 2: Run locally
1. Clone the repo
2. Create a virtual environment
3. Install common libraries

Suggested install:
- numpy, pandas, scikit-learn
- matplotlib, seaborn, plotly
- tensorflow or pytorch (depends on notebook)
